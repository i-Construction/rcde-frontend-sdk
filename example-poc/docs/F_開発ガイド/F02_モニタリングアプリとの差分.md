# F02: モニタリングアプリとの差分

## 1. 機能差分テーブル

| 機能 | モニタリングアプリ | PoC | 備考 |
|---|---|---|---|
| RCDE OAuth 認証 | あり | あり | 2-legged / 3-legged 対応 |
| 点群 3D ビューア | あり | あり | SDK の RCDE コンポーネント |
| 点群ファイルアップロード | あり | あり | SDK のアップロード機能 |
| 基準点管理 | あり（DB 永続化） | あり（メモリ内） | SDK の ReferencePointProvider |
| 距離計測・断面表示 | あり | あり | SDK の計測ツール |
| 差分解析（PCD Compare） | あり | **なし** | Lambda + WASM 依存 |
| 現場契約管理（AppSettings） | DB + superuser UI | **なし**（ID 直接指定） | DB 不要の設計 |
| メール通知 | あり（SES） | **なし** | AWS SES 依存 |
| ファイル共有・承認 | あり | **なし** | ワークフロー機能 |
| メモ機能 | あり | **なし** | DB 依存 |
| 管理画面（Admin） | あり | **なし** | superuser / admin ページ |
| 発注者/受注者ロール判定 | あり | **なし** | ロールベースアクセス制御 |
| Sentry エラー監視 | あり | **なし** | モニタリング |
| WASM LAS パーサー | あり | **なし** | wasm-las-parser |
| フォルダ管理 | あり | **なし** | DB 依存 |
| Inspector 設定永続化 | あり（DB） | **なし** | DB 依存 |
| 計測ポイント永続化 | あり（DB） | **なし** | DB 依存 |

## 2. 除外した機能の理由

### DB 依存の機能

- フォルダ管理、Inspector 設定、計測ポイント永続化
- PoC は Docker/DB なしの設計のため除外
- RCDE API がこれらの機能を提供するまで保留

### 外部サービス依存の機能

- 差分解析: Lambda + WASM 依存
- メール通知: AWS SES 依存
- エラー監視: Sentry 依存

### 業務固有の機能

- ファイル共有・承認ワークフロー
- 発注者/受注者ロール判定
- 管理画面

これらは shimz-monitoring-app 固有のビジネスロジックであり、汎用 PoC には不要。

## 3. アーキテクチャの差分

| 項目 | モニタリングアプリ | PoC |
|---|---|---|
| フレームワーク | Next.js 14 (App Router) | Next.js 14 (App Router) 軽量版 |
| 認証 | NextAuth + RCDE OAuth | 独自 API Route + Cookie |
| データベース | PostgreSQL (Prisma) | なし |
| オブジェクトストレージ | S3 / MinIO | なし（RCDE API 経由） |
| 状態管理 | Zustand + TanStack Query | なし（簡易 state） |
| Docker | あり（PostgreSQL, MinIO, Lambda） | なし |
| ファイル数 | 233+ | 約 20 |
| セットアップ時間 | 30分+（Docker build, DB migration） | 5分（npm install のみ） |

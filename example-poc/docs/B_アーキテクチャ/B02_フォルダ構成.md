# B02: フォルダ構成

## 1. ファイル構成ツリー

```
example-poc/
├── package.json            # 依存関係（Next.js + SDK のみ）
├── next.config.js          # Next.js 設定（transpilePackages）
├── tsconfig.json           # TypeScript 設定
├── .env.example            # 環境変数テンプレート
├── .gitignore
├── README.md               # プロジェクト説明
├── docs/                   # 設計ドキュメント（本ディレクトリ）
├── public/                 # 静的ファイル（空）
└── src/
    ├── app/
    │   ├── layout.tsx              # ルートレイアウト
    │   ├── page.tsx                # / → /login リダイレクト
    │   ├── login/
    │   │   └── page.tsx            # ログイン画面（2-legged / 3-legged 選択）
    │   ├── viewer/
    │   │   ├── page.tsx            # ビューアページ（SSR: トークン確認）
    │   │   └── ViewerClient.tsx    # RCDE コンポーネントラッパー
    │   └── api/
    │       ├── auth/
    │       │   ├── token/
    │       │   │   └── route.ts    # 2-legged トークン取得
    │       │   └── callback/
    │       │       └── route.ts    # 3-legged コード交換
    │       └── constructions/
    │           └── route.ts        # 現場・契約一覧プロキシ
    ├── lib/
    │   ├── rcde-server.ts          # サーバーサイド SDK クライアント
    │   └── auth-store.ts           # Cookie ベースのトークン管理
    └── components/
        └── ConstructionSelector.tsx # 現場・契約選択 UI
```

## 2. サーバーサイド / クライアントサイドの分類

### サーバーサイド（Node.js ランタイムで実行）

| パス | 役割 |
|---|---|
| `src/app/api/auth/token/route.ts` | 2-legged トークン取得 |
| `src/app/api/auth/callback/route.ts` | 3-legged コード交換 |
| `src/app/api/constructions/route.ts` | 現場・契約プロキシ |
| `src/lib/rcde-server.ts` | SDK クライアント生成（`clientSecret` 使用） |
| `src/lib/auth-store.ts` | HTTP-only Cookie 管理 |
| `src/app/viewer/page.tsx` | SSR: トークン確認後にクライアントに渡す |

### クライアントサイド（ブラウザで実行）

| パス | 役割 |
|---|---|
| `src/app/login/page.tsx` | ログイン UI |
| `src/app/viewer/ViewerClient.tsx` | RCDE コンポーネントのラッパー |
| `src/components/ConstructionSelector.tsx` | 現場・契約選択 UI |

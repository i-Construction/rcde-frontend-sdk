## 3. 後方互換性

- 既存の `RCDEClient`（`src/lib/rcde-client.ts`）はビューア内部のタイル取得に最適化されており、そのまま維持
- 新しい `RCDEClient2Legged` / `RCDEClient3Legged` は外部向けの完全な API クライアント
- 将来的に `RCDEClient` を廃止して統一することも可能だが、現時点では並行エクスポート
